# Open decisions and the defaults to use

Until the owner decides, use the default. Note in `NOTES.md` whenever a default shaped your work.

| # | Decision | Status | Default to assume |
|---|---|---|---|
| 1 | Licence of Prism itself | Decided | Open source, MIT or Apache-2.0. Add dual `LICENSE-MIT` and `LICENSE-APACHE` files when the first release is cut. Use only permissively licensed dependencies (MIT, Apache-2.0, BSD, zlib, MPL). Never copy GPL code. |
| 2 | Name | Decided | Keep "Prism". |
| 3 | Platform | Decided | Rust, wgpu and winit. Native Windows and macOS builds, plus a web build (PLAN.md 3.1). |
| 4 | Input devices | Decided | Mouse and keyboard only. The wheel only zooms. On trackpads, two-finger scroll pans, pinch zooms at the cursor, and orbit is by the Orbit tool or middle-drag only. Add a greyed-out **Help > Pen and tablet input** toggle. No pen or touch. |
| 5 | Separator in the measurement box | Decided | Locale-aware: comma between values where the decimal mark is `.`, semicolon where it is `,`. Always accept `;`. Units and separator are set in File > Document Settings. |
| 6 | Scripting and automation | Decided (stub) | Add a greyed-out top-level **Scripting** menu. No API yet. Keep the action registry and command log clean so one can be added later. |
| 7 | What the first usable build contains | Decided | Skeleton, Core Model, Viewport, Actions & Keys, Inference & Drawing, Edit Tools, Files & Formats. Nothing else until that build feels right. |
| 8 | Performance targets | Decided (provisional) | Reference machine: i7-5820K 3.3 GHz, 32 GB RAM, 8 GB VRAM. Stay interactive (orbit 30 fps or better, picking and inference under 16 ms) on a model about twice the size of a SketchUp file that struggles there (over about 50 MB). The first chunk that renders measures what that means in triangles and edges and records it in `NOTES.md`. |
| 9 | NURBS kernel | Open | Not needed yet. Design the edge and face types so exact curves and surfaces can be added (PLAN.md 1.1), but implement lines and planes only. |
| 10 | iPad | Open | Hosted web build only. Check that it runs at all and record the result in `NOTES.md`. |
| 11 | Existing Android video player in the repo | Decided | Deleted in the first commit of the plan. It is in git history. |
| 12 | Fonts under the SIL Open Font Licence | Decided | Allowed for bundled fonts (not code). Use IBM Plex Sans and IBM Plex Mono. |
| 13 | Large display type from the Motion Kit | Decided | Not used. Ignore the giant header type in `soft.html`, here and in any app screen. |
| 14 | Push/Pull of a ring face (a face with a hole, around another face) | Decided | The pulled face becomes the top; the bottom is not closed. Only Alt (new loop) keeps the original face in place. Golden case `pushpull_ring_face` is now verified. |
| 15 | What the Eraser does to the faces beside an edge | Decided (changed 2026-11-06) | As in SketchUp: erasing the edge between two faces **on one plane** merges them into one face (so it can be offset, pulled and so on). Erasing an edge where faces meet at an angle deletes every face that uses it. Erasing a hole's edge closes the hole. |
| 16 | Orbit, Pan and Zoom (O, H, Z) picked while another tool is active | Decided | They stay active after the mouse is released; Esc returns to the previous tool. They are not temporary. |
| 17 | What the Down arrow does while drawing | Decided | Down releases the lock (as in the feel test). It does not lock parallel or perpendicular. |
| 18 | Locking the Rotate tool's protractor | Decided | The protractor is a full circle. In Rotate, Up locks it to the plane of the face under it; you can then move the locked protractor to another place and click and drag there to start the rotation, as in SketchUp. Rotate uses the same snaps as the other tools. Built with Edit Tools. |
| 19 | Perpendicular guides while drawing | Decided | Not wanted for now: only "Parallel to Edge" guides, as in the feel test. |
| 20 | What is greyed out in menus, the dock and search | Decided (a standing rule) | Only what is actually built, even partly, is active; everything else is greyed. Keep it true as the project grows: when a tool or command gets built, make it active in the same change. In code, the action registry takes the list of tools from `prism_tools::session::TOOLS`, so a tool is only pickable once the session runs it. |
| 21 | Selecting points with edges and faces | Decided | Points are the glue between edges and faces. Box select takes the points in the box with the edges and faces, and Select All and triple-click take every connected point, so nothing is left behind when the selection moves (moving an edge or face always moves its points too). Shift or Ctrl with a double or triple click adds or removes the face-and-edges or the connected set, without touching the rest of the selection. "Connected" also crosses faces, so a pocket comes with the box it is cut into. |
| 22 | Copying a group | Decided | Copies of a group are independent at once; editing one never changes another. Only component instances are linked to a shared definition. |
| 23 | Glue to and Cut opening | Decided | Not in the first Groups & Components chunk; they come later. When built, show a small visual sign when a component can glue to the face under it, and put a global on/off toggle for gluing in the right-click menu (the owner found SketchUp's gluing hard to predict). |
| 24 | Double-click to open a `.prism` file | Decided | Double-clicking a file opens it **in the Prism that is already running**, in a new tab (#27); only if Prism is not running does it start. A file that is already open switches to its tab. Files & Formats part 1 opens a file named on the command line and declares the type in the Mac `Info.plist`. The rest comes with tabs (Files & Formats part 3): macOS sends the file to the running app as an Apple event, which winit does not pass on, so Prism adds a small handler; on Windows a second start hands the file to the running Prism and quits. Registering `.prism` with Windows needs an installer (the packaging step). |
| 25 | 3MF and the 0BSD licence | Decided | Write 3MF ourselves with `zip` and `quick-xml` (MIT). The `threemf` crate (0BSD) is not used, and 0BSD stays off the licence list. |
| 26 | What Rotate turns with nothing selected | Decided | As in SketchUp: Rotate works on the selection, or with nothing selected on the item under the cursor alone (like Move), not the whole connected body. Rotating a face that is attached to other faces twists it, and the attached faces fold into flat pieces (triangles where needed). |
| 27 | Several documents at once | Decided | Tabs in one window, not a new copy of the program per file (the owner's old SketchUp is slow to start a new copy). Each tab has its own document, undo history, selection, camera, tool state and autosave journal. File > New and Open make a new tab; closing a tab asks "Save changes?" for that document. Built as Files & Formats part 3, with #24. **Look (owner's choice):** a compact strip of tabs (22 points) just under the menu bar, as wide as the viewport: not floating over the viewport, and not a dropdown. |
| 28 | Code signing for the native builds | Open | Ship unsigned until the packaging step, and say so in the release notes. Then decide: Apple Developer Program (USD 99 a year) for macOS notarisation, and Azure Artifact Signing (about USD 10 a month, US individuals; check that Guam qualifies) or an OV certificate (about USD 150–500 a year) for Windows. See `docs/research/risks.md`. |
| 29 | Intersections of faces that pass through each other | Decided | Wherever two faces cross with no edge along the crossing, the system knows it, **whether or not the pieces are connected** (a shape pushed through another and still joined to it counts; the owner's example). Two things, as Edit Tools part 3 (after Files & Formats part 2). (1) **Inference** finds the crossings: a point where an edge goes through a face ("Intersection"), and the line where two faces cross, drawn as a dashed guide you can snap along, with its ends as points ("Face Intersection"). So you can trace one shape's outline onto another's faces. (2) **Edit > Intersect Faces** (with the model, with the selection) adds those crossing lines as real edges in one undo step, so the overlap can be erased or pushed through to make a tunnel. Planar faces use exact plane-plane intersection clipped to both faces; curved faces wait for the kernel. Model Health (PLAN 1.10) also lists faces that cross without an edge. |
| 30 | Faces on one plane after an edit | Decided (owner, 2026-11-08) | One rule for coplanar faces everywhere: after Push/Pull, Move, Rotate, Scale and copies, every plane holding a face the edit touched has its crossing edges split and its faces rebuilt as one set of regions, as drawing already does. Overlapping faces become one set of faces; where two faces meet back to back (a face pulled flush against another) both go, so the solids join; and an opening the edit left (where a new edge now closes it) gets a face. Push/Pull decides edge by edge: an edge whose other faces run along the push behind the face slides, so those faces stretch; every other edge gets a new wall. |
| 31 | Push/Pull on a solid | Decided (owner asked for one general rule, 2026-11-08) | **Where faces enclose space, Prism keeps the boundary of that space.** Push/Pull on a face of a closed solid is a boolean: pulling out adds the block the face sweeps through, pushing in removes it. After the pull, faces near the edit are cut where they cross, and each piece is kept only if the solid is on exactly one side of it, facing out (a piece facing in is turned round); an empty region gets a face where the solid is on one side only. This one rule removes walls left inside, joins blocks pulled into or flush against each other, swallows a smaller block, cuts a tunnel when a face is pushed out through the back, and closes the bottom of a post left floating. Faces that enclose nothing (a lone rectangle, an open box) keep the plain behaviour. Alt (new loop) keeps the original face on purpose. Move, Rotate and Scale do not cut solids (only the coplanar rule, #30, runs), so moving a box through another leaves crossings for Intersect Faces (#29). **Changed 2026-11-09 (owner): Push/Pull never passes through a face.** The face moves freely until it meets another face and stops there (letting go there merges them); a neighbour that leans over its path blocks it at once. So a pull now stops at a smaller block and joins it instead of swallowing it, and a face pushed out through the back stops flush with it (which still cuts the tunnel). Alt (new loop) is not limited. |
| 32 | Curves that are not lines or arcs, before NURBS | Decided (owner, 2026-11-09) | Until the NURBS kernel arrives (NURBS Spike, after Exact Curves), an operation that would make a curve Prism cannot store exactly (uneven Scale of a circle, a cylinder cut by a slanted plane, crossing cylinders, Follow Me along a freeform path) **falls back to fine straight segments marked approximate**. Model Health lists them, and NURBS can replace them later. Nothing is refused. **Built last** (owner, 2026-11-09): the fallback comes once the five exact parts are finished, not partway; until then those operations do what they do now. See `docs/research/exact-curves.md`. |
